# 闭环实验协议（跑数据之前写定）

日期 2026-09-29。目标：回答 `docs/v2_readability_diagnosis.md` 第六节的三个遗留问题，使 V2 论文形成闭环。本文件在任何新结果产生之前写成；之后若调整策略，在文末追加“变更记录”，不改动本文前面的内容。

## 数据划分

- **探索集**：已有的 36 个场景（FloorPlan201–218、301–318，其中 30 个评估场景 + 6 个开发场景）。这些场景在 m=3、基准暂停长度下的结果已被看过，任何新条件都在这里探索，允许多个条件并列比较。
- **确证集**：未使用过的同类新场景 FloorPlan219–230、319–330（共 24 个）。只在探索集上把“要确证的单一条件”定好之后跑一次，结果不再调整。

## 三个实验（均使用均匀初始候选，不依赖 LLM 服务）

| 编号 | 回答的问题 | 变量 | 固定 |
|---|---|---|---|
| E1 | 队伍变大时界会不会变松 | 机器人数 m ∈ {2,3,4,6} | 暂停长度尺度 λ=1 |
| E2 | 评估更贵时 CPU 增量是否显现 | 评估器：闭式积分 D=3（原设置）、闭式积分 D=12、网格重放 P=32 个起点 × D=12 长度 | m=3, λ=1；三种评估器的暂停长度均值相同，因此筛掉的候选数相同，只有单次评估成本不同 |
| E3 | 什么条件下按 J 搜索优于按 C 搜索再重排 | 暂停长度尺度 λ ∈ {0.5,1,2,4}，与 m 交叉 | 闭式评估器 |

- 每个条件：81 个评估任务 × 10 个搜索种子（6101–6110）× 5 种方法（J 搜索不筛选 / 名义筛选 / 临界路径筛选，C 搜索加重排，均匀采样）。预算 256 个候选，束宽 4，与原实验相同。
- 暂停长度：训练用 λ×(0.1,0.2,0.4)×T，留出测试用其 1.5 倍（与原实验的测试比例相同）。T 取初始 12 个候选的最小名义完工时间。
- m>3 时新增机器人的起点在可达格点中按最远点取；机器人 1 只能搬运，其余机器人可开关门（与原实验规则一致）。
- 全部实验单元格都会汇报，包括不利的。统计方式同原文：先对种子、再对任务平均，以场景为单位做配对自助法（10,000 次）。

## 判据（事先写定）

1. **正确性**：所有筛选规则必须与不筛选产生逐位相同的搜索轨迹（程序内断言），跳过的候选事后全部重算并核对，任何不一致视为实验失败。
2. **E1**：报告各 m 下的评估次数占比和相对名义筛选的额外节省。若额外节省在 m=6 下降到接近 0，论文写明适用范围随 m 缩小，不外推。
3. **E2**：以评估与建调度的耗时比 ρ 为横轴，报告 CPU 节省。“CPU 增量成立”的判据：在 ρ 较大的设置中，相对名义筛选的额外 CPU 节省的 95% 区间不含 0。若不成立，论文保留“增量只在评估次数上”的表述。
4. **E3**：主对比为 J 搜索相对 “C 搜索 + 重排” 的留出 J 差（负值表示 J 搜索更好）。
   - 探索集上若某个 (m, λ) 条件的区间不含 0，则在确证集上只跑这一个条件；确证集上仍不含 0 才写“存在 J 搜索占优的条件”。
   - 若探索集上没有任何条件的区间不含 0，论文改写为“已决定按 J 搜索时的安全加速”，并如实报告各条件的零结果。
   - 多个条件并列比较，探索集上的“显著”只作为选择确证条件的依据，不作为论文结论。

## 不做的事

- 不删除或替换任何已有结果；旧结果与新结果分开存放（`results/closure/`）。
- 不因结果不好而改变判据；调整实验设置只能通过“变更记录”公开进行。

## 变更记录

**2026-09-29，探索集 E1/E3 结果已看到，确证集数据尚未采集。**

- 探索集上 E1/E3 的 16 个 (m, λ) 条件中，J 搜索相对 “C 搜索 + 重排” 的区间几乎都不含 0。原判据 4 要求“只确证一个条件”，但多个条件同时满足，无法按效应大小挑选而不引入选择偏倚。
- 因此确证集改为：**同一套 16 个条件、同样的 10 个种子全部重跑，不做挑选**。主确证对比事先定为原论文的默认设置 (m=3, λ=1)（它不是按效应大小选出的），其余 15 个条件作为次要结果，全部汇报。
- E2（评估成本）在探索集上按判据 3 已满足，但作为同样不挑选的确证，在确证集上以相同三种评估器重跑一次。
- 结论措辞约束：探索集结果只能写作“探索性”；只有确证集结果才能写作“确证”。
- 已知的设置假设（写入论文的局限）：m>3 时新增机器人起点按最远点选取；机器人 1 仍只能搬运；初始候选仅用均匀采样，不含 LLM。

**2026-09-29，对抗审查之后、确证集运行之前。** 两个独立的外部模型（Gemini 3.1 Pro、GPT-OSS 120B，经 agy 只读审查）审查了协议、运行器和分析脚本。采纳的修改如下，均在确证集数据产生之前定下：

1. **更强的 C 基线。** 原 “C 搜索 + 重排” 在名义完工时间 C 打平时按生成先后取前，可能因整数代价大量打平而冻结搜索。新增基线 `C_rerank_tb`：束按 (C, J, 序号) 排序，打平时用 J 打破（J 本来就对全部候选算过，不增加评估）。**主确证对比改为 J 搜索相对 `C_rerank_tb`**，`C_rerank`（原基线）作为次要结果保留。若 J 只在弱基线上占优，论文不写“J 搜索占优”。
2. **方法执行顺序随机化**（按任务、m、种子确定性打乱），排除计时顺序效应；结果与顺序无关的断言（三种筛选轨迹必须一致）保持不变。
3. **敏感性实验**（探索集，m ∈ {4,6}，λ ∈ {1,2}）：(a) 暂停的绝对长度固定为 m=3 时的取值（原设置里暂停长度是视界 T 的比例，T 随 m 变小，绝对长度随之变短）；(b) 新增机器人起点改为随机而非最远点。
4. **多重比较：** 16 个 (m, λ) 单元格的次要结果用 Holm 校正后的区间/判断汇报；主确证对比仅一个，不需要校正。
5. **不采纳的审查意见**及理由：C1–C3（两种方法都对全部 256 个候选算 J，评估数相同）、H1/H3（以 30 个场景为聚类单位是正确层级）、M1（m=2 时开门机器人只有 0 号是规则，不是抽样偏差）、“下界在 m 大时数学上等价于名义筛选”（b>0，只按 1/m 缩小）。
6. 已知局限（写入论文）：候选表示只有一个全局开/关门机器人；暂停长度按视界比例设定。

**2026-09-29，探索集用冻结代码重跑完成，确证集运行之前。**

- 探索集（冻结代码、含 `C_rerank_tb`、随机化顺序）：16 个 (m, λ) 单元格中，J 搜索相对 `C_rerank_tb` 的留出 J 差在 m≥3 的大多数单元格区间不含 0（m=3, λ=1：−0.33 [−0.58, −0.10]），m=2 与 m=6, λ=0.5 不含显著差；对弱基线 `C_rerank` 差更大。评估成本实验：ρ=8.43 时临界路径筛选相对名义筛选的额外 CPU 节省为 13.42 ms [11.91, 15.00]，ρ=0.40 时为 0.22 ms [−0.23, 0.68]。敏感性运行（绝对暂停长度、随机起点）方向一致，m=6 下差距变小。未发现实现错误，轨迹一致断言全部通过。

## 确证集结果（2026-09-30 采集，代码与协议均未再改动）

原始数据 `results/closure/confirm_cost`、`results/closure/confirm_scaling`；汇总 `results/closure/analysis_confirm_*`；论文数字由 `tools/make_closure_assets.py` 自动生成（`paper/v2/results_closure_numbers.tex`）。24 个新场景、66 个任务、10 个种子。

- **正确性**：所有筛选规则与不筛选轨迹逐位一致（程序内断言），跳过候选事后全部核对，无一例外。
- **E1（评估次数）已确证**：相对名义筛选的额外节省在 16 个单元格全部区间不含 0；λ=1 下 m=2/3/4/6 分别为 41.0/26.5/18.0/10.6%，随 m 减小，随 λ 增大后趋平。
- **E2（CPU）已确证**：ρ=0.39 时额外 CPU 节省 −0.05 ms [−0.47, 0.38]；D=12（ρ=0.67）0.60 ms [0.19, 1.02]；网格重放（ρ=8.37）13.20 ms [11.63, 14.89]。
- **E3 主确证对比未确证**：(m=3, λ=1) J 搜索 − `C_rerank_tb` = −0.16 步 [−0.44, 0.14]（探索集为 −0.33 [−0.58, −0.10]，效应在新场景上缩小）。对原弱基线 `C_rerank` 为 −0.44 [−0.76, −0.14]。
- 次要结果（16 个单元格，对 `C_rerank_tb`）：14 个点估计为负，8 个原始区间不含 0，Holm 校正后 3 个显著（m=3 λ=0.5、m=3 λ=4、m=6 λ=2）；最大效应 m=3 λ=4：−1.28 [−1.93, −0.68]。对 `C_rerank`：16 个为负，13 个区间不含 0，11 个 Holm 显著。`C_rerank_tb` 比 `C_rerank` 最多好 3.19 步，说明弱基线的大部分差距来自“打平时的取舍”。
- 论文据此的写法：J 搜索只在长暂停条件下确证优于带 J 打破平局的名义搜索；默认设置下未确证；论文定位为“已决定按 J 搜索时的安全加速”。
